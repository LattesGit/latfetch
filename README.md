# LatFetch

A lightweight Windows system information tool written in C#.

LatFetch displays useful information about your Windows system directly from the terminal.

## Features

- Windows version
- Username and computer name
- System uptime
- CPU information
- GPU information
- RAM usage
- Storage usage
- Network adapter and IPv4 address
- .NET runtime information
- Running process count
- Minimal and category-specific modes

## Usage

Run LatFetch normally:

```powershell
LatFetch.exe
